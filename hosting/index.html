Featured project

Athana Melody

2026

Founder, designer and sole developer/Web app (PWA) and native Android app/Free and ad-free/Source and releases on GitHub

A music player for every kind of song file: MP3, AAC, M4A, OGG, Opus, FLAC, WAV and AIFF. Lossless files reach the audio output untouched. Published on GitHub as Kanata Hiroshi.

Playback engine

  • Built the Android app in Flutter and Kotlin with a background playback service, lock-screen controls, and its own decoder and audio output with bit-perfect and 24-bit float modes.
  • Wrote the web version as an installable offline app with a service worker, reading covers, tags and embedded lyrics from the user's own files.

Audio tools

  • Added a 10-band equalizer, loudness measurement (LUFS), spectrogram, true bit-depth and hi-res checks, dynamic range and clipping detection, volume normalisation, A-B loop and fades.

Connections

  • Added WebDAV for home servers and NAS drives with HTTP Basic authentication. Server passwords are encrypted with the Android Keystore (AES-GCM), so backups cannot read them.
  • Added streaming from Google Drive without filling the phone's storage.
  • Matched songs with MusicBrainz and the Cover Art Archive, handling romanized titles, artist aliases and joined artist credits, within each service's rate limit. Added synced lyrics, romaji and translation into 18 languages.

Privacy and delivery

  • Made privacy a feature: no account, no tracking, an Offline mode, a switch for every online service, local backup and restore, and a one-tap erase.
  • Built an in-app updater that checks GitHub Releases, downloads the APK with a progress bar and hands it to Android's installer.
  • Ran the whole release: README and changelog writing, GitHub Pages hosting, a first-launch welcome, and a rare Ko-fi support prompt that can be switched off for good.
